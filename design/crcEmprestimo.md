# Cartão CRC — Emprestimo

## Responsabilidades
- Registrar data de retirada
- Calcular e informar data de devolução de acordo com o usuário
- Associar a obra ao usuário responsável pelo empréstimo
- Registrar devoluções e identificar atrasos
- Informar se o empréstimo está ativo
- Renovar empréstimos ativos
