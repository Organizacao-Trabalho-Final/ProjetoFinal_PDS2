# Cartão CRC — Usuarios

## Responsabilidades
- Armazenar os usuários cadastrados e seus IDs.
- Cadastrar usuários.
- Remover usuários.
- Buscar usuários por nome, CPF, ID ou índice.
- Informar o tipo de usuário cadastrado.
- Gerenciar a memória dos usuários cadastrados.
